# Global Financial & Sales Analytics BI Solution

## Project Overview
An end-to-end Business Intelligence solution built for Tailwind Traders using Power BI, DAX, Python, and Excel. This project processes multi-national transaction datasets, models financial metrics, and delivers dynamic executive reporting dashboards.

## Key Features & Deliverables
**Data Cleansing & ETL:** Cleaned and transformed multi-currency sales datasets using Python (pandas) and Power Query.
**Data Modeling:** Built a relational Snowflake schema with bi-directional cross-filtering and a dedicated DAX Calendar table.
**Financial Calculations:** Authored complex DAX measures (`TOTALYTD`, `DATESQTD`, `RELATED`) to convert multi-currency metrics to standardized USD revenue and profit margins.
**Executive Dashboards:** Created interactive, mobile-optimized reports featuring trend analysis, geographic slicers, and KPI cards.
**Automation & Performance:** Optimized DAX query load times to under 200ms using Performance Analyzer and configured automated weekly email alerts and KPI thresholds.

## Tech Stack
**BI & Visualization:** Power BI Desktop, Power BI Service
**Languages:** DAX, Python (pandas)
**Data Management:** Microsoft Excel, Power Query
